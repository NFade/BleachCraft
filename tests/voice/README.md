Voice-matcher phrase fixture (phase 5): ASR-style positives per command and neutrals that must never fire, for the matcher unit tests.
Schema: {"version":1, "positives":[{"command","lang","text","kind":"canonical|variant|asr_error|partial"}], "neutrals":[{"lang","text"}]}; lang is ja-JP, en-US or ru-RU.
Source: design/VOICE_PHRASES.md (sections 1, 2, 3.2, 4), trimmed to 10-15 positives per command plus new ASR-style variants; neutrals are section 4 plus new near-misses. State/item gating is not stored here (spec 3.3).
Decision (orchestrator, overrides spec 3.4): "bank eye", "bankeye" and "bank i" are positives for rukia.bankai.release and byakuya.bankai.release, and "bank eye" is removed from the neutrals.
Generated by hand from the spec; validate with python -I json load (counts and duplicate check).
