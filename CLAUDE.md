# MineBleach: правила для Claude Code

Fabric 1.21.1, Yarn, mod id `reiatsu_test`, код в `mod/`. Пользователи пишут по-русски, ответы короткие (до 200 слов), код, файлы и коммиты по-английски.
Состояние проекта: `STATUS.md`. `LOG.md` и `STATUS.md` не править, `LOG.md` целиком не читать (230 КБ).
Открывай Claude Code из корня репозитория, иначе этот файл не подхватится.

## Экономия токенов (обязательно)
1. Один этап = один чат. Контекст около 200k токенов, конец этапа или примерно 100 вызовов инструментов: сам предложи пользователю handoff и напиши его по `docs/HANDOFF_TEMPLATE.md` (до 1.5k токенов, только то, чего нет в коде, `STATUS.md` и git; правила из этого файла в handoff не повторять) в `NEW_CHAT_PROMPT_<имя>.md` (не коммитить). Этап не закончен, но контекст раздулся: `/compact`.
2. Пауза дольше 5 минут стирает кэш и перезаписывает весь контекст. Перед паузой (сборка, обед) закрой чат с handoff или сделай `/compact`. Сборки и долгие команды в фоне, не ждать циклом `sleep`.
3. Bash: вывод только через `grep -E`, `tail -5` или в файл. Не `cat` больших файлов, не печатать логи Gradle и игры. Число тестов из `mod/build/test-results/test/*.xml` (атрибуты `tests=`, `failures=`), не из лога.
4. Read: `offset`/`limit`, `wc -l` сначала. Большие документы (`design/*.md`, `MASTER_PROMPT.md`, `research/`) целиком не читать: найди раздел в `design/INDEX.md`, читай с `offset`/`limit`. `docs/archive/` и `design/results/` не читать без нужды. Повторно один и тот же файл не читать.
5. Картинки: перед просмотром уменьшить до ширины около 1500 px, один лист сравнения вместо многих кадров, не смотреть одно и то же дважды. Blockbench: сначала `analyze_animation`, превью 1-2 момента и один вид.
6. Скрипты длиннее 30 строк писать через Write во временный файл (папка scratchpad), не heredoc-ом. Один сборочный прогон на пачку правок.
7. Субагенты: только на малые задачи. Один агент = один результат (файл, функция, замер, отчёт), до 30 вызовов инструментов, потом отчёт даже неполный (напиши это в промпте). Целый этап агенту не отдавать: основной чат делит этап на малые задачи и раздаёт. Не больше двух параллельно, точный промпт (файлы, критерии, формат ответа до 200 слов). Поиск по коду отдавать `Explore` на Haiku. Не воскрешать старых агентов с большим контекстом, не опрашивать (уведомление придёт само). Агент длиннее 60 ходов стоит вдвое дороже за ход и даёт три четверти расхода на агентов.
8. Инструменты ToolSearch грузить одним вызовом списком. Базовый контекст нового чата около 70k токенов (системный промпт, MCP, skills): неиспользуемые MCP-серверы и skills отключи в настройках.

## Модели (по максимуму Haiku)
- Haiku: поиск по коду, чтение и сводки логов и документов, git, запуск сборки и подсчёт тестов, копирование и переименование файлов, механические правки по готовому плану, документация. Субагенты по умолчанию на Haiku (`CLAUDE_CODE_SUBAGENT_MODEL` в `.claude/settings.json`).
- Sonnet: правки в нескольких файлах, миксины, математика и геометрия (повороты, матрицы), поиск причины непонятной ошибки, дизайн анимаций. Такому субагенту передай `model: sonnet` явно.
- Opus только по прямой просьбе пользователя.
- Модель выбирай в начале нового чата (`/model haiku` для рутины, `/model sonnet` для сложного этапа). Смена модели посреди длинного чата сбрасывает кэш и дорого стоит.
- Если Haiku два раза не справился, дальше не бейся: передай Sonnet, а не гоняй попытки.

## Проект
- Сборка: `cd mod && ./gradlew build 2>&1 | grep -E "error:|FAILED|BUILD"`; `JAVA_HOME` JDK 21, `GRADLE_USER_HOME` на отдельный диск.
- `core/` без импортов Minecraft (`CorePurityTest`). Yarn-имена проверять `javap` по jar, не угадывать.
- `.java` часто CRLF: правь маленьким Python-скриптом (`io.open(..., newline='')`) или `sed`, не многострочным Edit.
- Игру не запускать без просьбы. Коммит и пуш только по прямой просьбе, в новую ветку (не в чужие `gin-uryu`, `finish-r7`, `r11-merged`).
- Репозиторий публичный: не коммитить `refs/`, `.blend`, аудио, видео, кадры аниме. Better Combat и playerAnimator только как зависимость.
- Dev-файлы (`fx_override.json`, `pose_override.json`) вне git перекрывают код: при смене чисел проверь их.
- Анализ расхода токенов: `python -I tools/token_report.py --keyword minebleach` (читает только логи).
