# R11 T0: слой конфигов (сделано в коде, тесты зелёные, в игре не проверено)

Сделано:
- `core/config/ConfigMigrations` (чистая): версия конфига, таблица «прежнее умолчание -> новое», `migrate()` меняет только значения, равные старым умолчаниям. Файл без версии = версия 1.
- `core/config/Cfg`: терпимое чтение (мусор -> умолчание, число зажимается).
- `ModConfig.migrate()`: при старте ставит `configVersion`, для старого файла делает копию `reiatsu_test.json.bak_v1`, пишет лог `[config] updated N keys from v1 to v2`. Нечитаемый файл не трогается.
- `ModConfig.loadSection(...)`: общий загрузчик новых секций (первая: `mech`).
- `/reiatsu reload` (оператор): миграция + перечитывание секций kido, bladeFlight, mech. voice и frost требуют рестарта.
- Таблица ключей: `design/results/r11_config_keys.md`.
