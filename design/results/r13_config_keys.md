# R13: новые ключи конфига

Серверный файл `config/reiatsu_test.json`, секция `uryu` (пишется с умолчаниями при первом запуске, перечитывается командой `/reiatsu reload`, без пересборки). Лук читают и сервер (выстрел, откат, Rage), и клиент (анимация натяжения), поэтому в одиночной игре меняй один файл; на выделенном сервере клиентский файл держи в тех же числах.

| Ключ | Файл | Умолчание | Диапазон | Что делает |
|---|---|---|---|---|
| uryu.bow.minPower | server (и клиент для анимации) | 0.5 | 0..1 | наименьшая сила натяжения, при которой отпускание стреляет; ниже ничего не летит (тихий щелчок) |
| uryu.bow.fullDrawTicks | server/клиент | 24 | 4..200 | тиков до полной силы (кривая ванильная: `(t*t+2t)/3`, t = тики / это число) |
| uryu.bow.damage | server | 3.0 | 0..40 | урон обычной стрелы при полной силе до Focus и Blut Arterie (HP) |
| uryu.bow.damageCurve | server | 1.0 | 0.25..4 | урон = damage * сила^кривая (больше 1: короткое натяжение теряет больше) |
| uryu.bow.cooldownTicks | server | 14 | 0..400 | наименьший промежуток между двумя выстрелами (отпускание–отпускание) |
| uryu.rage.arrowTenthsPerHp | server | 5 | 0..1000 | Rage (десятые очка) за 1 HP урона обычной стрелы до брони |
| uryu.rage.arrowMaxPerHitTenths | server | 30 | 0..1000 | потолок Rage за одно попадание стрелы |
| uryu.rage.abilityArrowsPayCastReward | server | true | bool | стрелы и удары способностей Урью (Z, крылья, Licht Regen, Sternenstaub, Sprenger, Seele) платят фиксированную награду каста `rage.abilityHitTenths` один раз за каст, а не по 3.0 за каждую стрелу |

Клиентские dev-ключи (вне git, `run/fx_override.json` и `run/pose_override.json`, горячая перезагрузка):

| Ключ | Файл | Умолчание | Что делает |
|---|---|---|---|

| fp_bow.left.rot | pose_override.json | `[0, 0, -62]` | поворот предплечья руки с луком (минус: рука идёт из левого нижнего угла вправо) |
| fp_bow.idle.rot / idle.grip / idle.left.rot | pose_override.json | `[30, 0, -32]` / `[-0.45, -0.84, -1.10]` / `[0, 0, -80]` | та же поза в покое (лук опущен, наклонён вправо) |
| fp_bow.right.off / right.rot | pose_override.json | `[0.22, -0.12, -0.06]` / `[0, 0, 24]` | рука, натягивающая тетиву |
| uryu.tp.drawArmYaw | fx_override.json | -30 | градусы, на которые рука тетивы (3-е лицо) повёрнута к середине тела |

| uryu.fp.arrowX / arrowUp | fx_override.json | 0.02 / 0.04 | сдвиг модели стрелы на ложе лука от 1-го лица (были 0.14 / 0.05) |
| petalBlade.tpWidth | fx_override.json | 2.2 | во сколько раз толще лепестковый меч Бьякуи от 3-го лица |
| petalBlade.tpGlow / tpGlowAlpha | fx_override.json | 3.0 / 0.32 | размер и прозрачность розовой оболочки вокруг меча от 3-го лица (оболочка 1.0 = выкл.) |
