## Что сделано

### Инфраструктура
- `core/combat/CastGesture` (чистая математика): таймлайн по каналам. Строка = `[t, значения..., ease]`. Значения это ДЕЛЬТЫ от удерживаемой стойки (`fp_two.pos/rot`), поэтому подстройка стойки двигает все жесты.
  - `R` (6): `px py pz rx ry rz`: правая рука вместе с мечом как одно тело (поворот вокруг точки между кулаками, как удары и блок). `rx` < 0 клонит клинок вперёд-вниз (примерно -90 от стойки: горизонтально), `rx` > 0 назад на себя, `rz` > 0 уводит остриё влево, `ry` крутит клинок вокруг оси.
  - `L` (7): `px py pz arx ary arz free`: свободная левая рука. `free` 0 = кулак едет на рукояти вместе с мечом (дельта поверх), 1 = стоит на месте стойки независимо от меча (дельта поверх). `arx..arz` довёрт руки вокруг кулака поверх `two.left.arm.rot`.
  - `C` (4): камера `pitch yaw roll fov` (pitch > 0 вверх). `TR`/`TL` (3): третье лицо, `pitch yaw roll` руки с мечом и другой руки (pitch < 0 поднимает руку вперёд, roll > 0 отводит наружу).
  - Ease: 0 smooth, 1 out, 2 in, 3 linear, 4 spring (перелёт). Плюс: `orbit` (круги 'P' рука, 'T' острие, 'L' левая), `vib` (тремор), `holds` (время жеста замирает на `len` секунд: Absolute zero 2.0 + 1.0 с, Hakuteiken 1.4 + 0.1 с), огибающая `in/out` (вход и выход в стойку), `sustain` (держится, пока ключ зажат).
  - Перевод из таблиц проекта: `rx_проекта` (клинок вертикален = -85) в моей системе это `Δrx = -90 - rx_проекта`; всё, что в проекте «S rx», пересчитано.
- `core/combat/CastGestures`: шипнутые жесты и таблица `effect_event id -> ability id` (`idForEffect`): 1..4, 10 (seal), 20..23, 30..33, kido 50..52. Нет жеста: 11 (конец банкая), 34 (Senkei, не включён), 40, 41.
- `client/model/FpCast` (диспетчер): `ClientNet` после `FxEvents.onEffectEvent` зовёт `FpCast.onEffectEvent` (одна строка; `FxEvents`/`ServerFx` не тронуты). Каждому кастеру (свой и чужие) заводится прогон по `casterId`; новый жест перекрывает старый кроссфейдом 0.15 с. Для Byakuya shikai release жест подстраивается под `release.pinkTime` (ключи после 0.4 сдвигаются), `ShikaiDissolve` не тронут.
- Первое лицо: `FpMotion.frame` прибавляет `R` к позе (плюс гасит дыхание стойки), `FpMotion.renderLeftGuard` ведёт свободную левую руку (`L`), `FpCast.renderFreeHands` рисует пустые руки (банкай Бякуи, предмета в руке нет; ваниль там руку не рисует). Свободные руки поднимаются снизу экрана около якорей `free.anchor_r/l`.
- Камера: `GameRendererMixin` (второй inject в `tiltViewWhenHurt` + добавка к `getFov`): pitch/yaw/roll/FOV. Под `reduceMotion` и `photosensitiveSafe` камера = 0; масштаб `screenFxScale * fp_cast.cam_scale`. Работает только от первого лица.
- Третье лицо: `TpCastLayer` (playerAnimator, приоритет 1600: выше стойки 1500, ниже удара BC 2000), только руки, `rightItem` не трогаю (см. tp_pose.md и bc5). Для каждого каста минимальный жест: рука с мечом вперёд/вверх, другая отведена.

### Хук для роя (В)
- `ClientState.steering()` (по умолчанию false) и `ClientState.setSteering(boolean)`; сбрасывается при смене игрока. Пока true и в руке Zanpakuto: жест `steer` держится (рука с мечом вынесена вперёд, левая рука дирижирует кругом r=0.05, 0.8 Гц); отпускание проигрывает возврат (0.5 с) и огибающую. Параметры в `fp_cast."steer"` (`sustain` 0.25 с). Вызвать `ClientState.setSteering(true/false)` из кода клавиши (BladeSteer) должен другой агент.

## Как включить/отключить
`mod/run/pose_override.json`, секция `fp_cast` (switches уже записаны):
- `"enabled": 0` выключает всё; `"fp"`, `"tp"`, `"cam"` (0/1) по отдельности; `"scale"` амплитуда рук, `"cam_scale"`, `"speed"` масштаб времени.
- `"free.anchor_r"` [-0.38,0.30,-0.05], `"free.anchor_l"` [0.45,0.30,-0.05], `"free.arm_rot"` [0,0,0]: где висят пустые руки (блоки, раскладка правши).
- Один жест: `"fp_cast": {"rukia.shikai.release": {"enabled": 0}}` выключает; ключи `dur`, `in`, `out`, `sustain`, `R`, `L`, `C`, `TR`, `TL`, `orbit`, `vib`, `holds` заменяют канал целиком. Все шипнутые строки лежат в `design/results/fp_cast_rows.json` (сгенерировано из `CastGestures`; скопировать нужный жест в `fp_cast` и править; в игру этот файл не грузится). Перечитывается при правке файла (dev, ~0.15 с). Ключ id содержит точки, это нормально (один ключ объекта).
- Для продакшена (без dev-файла) работают значения из `CastGestures.java`.

## Проверить в игре (UNVERIFIED)
1. Старт без ошибок миксина (`GameRendererMixin` второй inject в `tiltViewWhenHurt`), слой `TpCastLayer` зарегистрирован, лог `[fpcast]` пуст.
2. Знак камеры: pitch > 0 должен быть «вверх» (в миксине `-pitch` на X), yaw > 0 вправо; roll не проверен. Если наоборот, поменять знак в `GameRendererMixin.reiatsu$castCamera`.
3. Левая рука при `free` 1: стоит на месте стойки, не падает за кадр; знак `x` для левши (зеркало `i`).
4. Rukia shikai (/release или E): Mae, три танца (Z/H/B), банкай release и Absolute zero: острие/клинок не обрезается верхом экрана (`rx` +50..+58 над головой), заморозка позы 1.0 с совпадает с заморозкой мира, камера тоже стоит.
5. Byakuya shikai release: рука рвётся вперёд ровно при начале распада (0.4 + shift по `release.pinkTime`); кулак не съезжает на рукояти (FIST по модели).
6. Byakuya банкай: пустые руки появляются снизу, в нужных местах (`free.anchor_*`, `free.arm_rot`: ванильная рука левой стороны может идти не в ту сторону), предмета в руке нет; Scatter/Hakuteiken. Если на событии 4 стейт ещё не успел смениться на банкай, на первых кадрах работает режим «меч в руке» (R двигает рукоять).
7. Кидо с мечом (вынут) и в SEALED; левша; reduceMotion/photosensitiveSafe (камера 0).
8. Третье лицо: F5 свой и чужой игрок: знак `roll` (наружу): правая рука `+z`, левая `-z`. Дельты ложатся на стойку TpPose, не должны ломать удар BC (слой BC выше).
9. `steering`: `ClientState.setSteering(true)` из консоли/другого кода держит жест, отпускание возвращает руки.
10. Влияние кроссфейда при двух кастах подряд.
