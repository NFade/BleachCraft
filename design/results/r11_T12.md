## Правовое правило (сказать пользователю один раз)
Звуки и голоса из аниме защищены авторским правом, а репозиторий публичный. Поэтому мод работает без этих файлов (играют прежние ванильные звуки), а клипы пользователь кладёт у себя локально.
`.gitignore` закрывает `mod/src/main/resources/assets/reiatsu_test/sounds/anime/`, `sounds_local/`, `reiatsu_test_anime_sounds/` (и `.zip`). Тест `SoundSheetTest` проверяет, что в `mod/src` нет аудио и видео вне этой папки.
Источник сцен (старое ТВ-аниме 2004..2012 или Thousand-Year Blood War 2022+) пользователь не выбрал: колонка «сцена» в листе пуста. Реплики сэйю, имена приёмов, крики и музыка по умолчанию не используются.

## Как устроено
Одно событие = один МОМЕНТ способности или игры (не один ванильный слой). Момент с несколькими ванильными слоями (парирование: звон, колокол, трезубец ...) остаётся таким же без файла; с файлом играет один клип вместо всех слоёв.
- `core/sound` (чистая, без Minecraft): `SoundIds` (166 id и константы), `SoundEntry` (запись конфига), `SoundCatalog` (умолчания: интервал, дальность, категория), `SoundMap` (чтение/запись JSON и `decide(...)`: клип / запасной / тишина / «рано»).
  Клиент задаёт `Availability` (загружено ли событие), `core` Minecraft не знает.
- `registry/ModSounds`: по `SoundEvent` `reiatsu_test:<id>` на каждый id. `assets/reiatsu_test/sounds.json`: вариант 1 каждого события (`anime/<группа>/<остальное>_1`, `attenuation_distance` = дальность).
- Загружен ли клип (клиент): `SoundManager.get(id) != null && getWeight() > 0` (событие есть в sounds.json и файл существует; проверено по байткоду `WeightedSoundSet`).
- `client/fx/FxSound` (единая клиентская точка): `play(from, событие, ваниль, x,y,z, высота, громкость)`, `playEvent(...)` (только клип), `ui(...)`. Без клипа играет ваниль с той же громкостью и высотой, что раньше (множитель громкости события по умолчанию 1.0); с клипом: громкость и высота из конфига события,
  дальность, `fxSoundVolume`, ducking. Ограничитель 24 живых звуков, дедупликация 0.05 с, лимиты dripstone/petals остались (для запасного пути).
- `server/ModSound.play(мир, событие, x,y,z, ваниль, громкость, высота)` (единая серверная точка): шлёт `SoundCueS2C` игрокам в радиусе `range` (не меньше 16 * громкость, как у ванили); клиент решает, клип или ваниль. Заменены все `world.playSound` в `BlockParry` (парирование, блок) и `IceWall` (старт, слой, попадание, обвал). `AbilityExecutor`, `KidoManager`, `TempBlocks` своих звуков не играли (кидо и способности звучат клиентскими FX), менять там нечего.
- Заменены все ~225 вызовов `FxSound.play`/`x.sound`/`x.soundAt`/`FxSound.ui` в 22 файлах клиента (+ звук листа книги и отказа в `ClientNet`). Тест запрещает строковые литералы вместо события и прямой `playSound`/`SoundEvents`/`PositionedSoundInstance` вне двух точек.
- Новое: `general.pressure.release` (T7, `PressureFx.start`, громкость по силе эффекта, без ванильного звука, раньше был тихий).
- `config/reiatsu_sounds.json`: см. `r11_config_keys.md` (раздел «Звуки»). Создаётся при первом старте (сервер или клиент), все события с умолчаниями. Сервер перечитывает по `/reiatsu reload`, клиент сам раз в секунду.
  Чтение терпимое (плохое значение даёт умолчание), нечитаемый файл не перезаписывается.

## Что положить пользователю
1. Выбрать источник сцен и отвечать на вопросы листа `design/results/r11_sound_sheet.md` (166 событий: 149 подключено, 17 резерв: удары мечом, урон/смерть, рейдж/мана растут, разрушение блоков T9, Сенкей, весь Uryu).
2. Формат клипа: **Ogg Vorbis, моно, 44100 Гц**, длина по колонке листа (обычно 0.1..3 с), пик около -1 dB, без тишины в начале. Имя: `sounds/anime/<группа>/<остальное>_N.ogg`, например `general/parry_1.ogg`, `byakuya/bankai_hakuteiken_strike_1.ogg` (колонка «файл» листа даёт точное имя).
3. Где: либо `mod/src/main/resources/assets/reiatsu_test/sounds/anime/` (для разработки; в git не попадёт), либо локальный ресурспак.
4. Проверка и сборка (стандартная библиотека Python, ffmpeg по желанию): `python -I tools/sounds_check.py` (отчёт: что есть, что не так, чего не хватает), `--dir sounds_local` (другая папка), `--all` (с резервными), `--normalize SRC OUT` (нужен ffmpeg: любой формат -> mono 44.1 кГц ogg, -18 LUFS, пик -1.5 dB, срез тишины),
   `--pack reiatsu_test_anime_sounds [--zip]` (ресурспак `pack.mcmeta` формата 34 + клипы + `sounds.json` с вариантами _2.._N; положить в `resourcepacks/` и включить). Скрипт ничего не скачивает и не лежит в сборке.
5. Варианты: `_2`, `_3` ... кладутся в ресурспак (`--pack` пишет их в его `sounds.json`; списки звуков паков складываются), мод выбирает случайный, подряд не повторяя. Свой клип можно подключить и без переименований: `events.<id>.files` в конфиге.
6. Лог: в sounds.json события ссылаются на файлы, которых нет; игра пишет на каждый такой файл строку WARN «File ... does not exist, cannot add it to event» (до 166 строк при старте и при F3+T). Это ожидаемо, звук не ломает (UNVERIFIED: формулировка и число строк по исходникам, не по запуску).

## Лист звуков
`design/results/r11_sound_sheet.md`: по персонажам и состояниям (общие, UI, Бьякуя шикай и банкай, Рукия шикай и банкай, Gin, Uryu, кидо): id, где вызывается, что слышно (ориентир своими словами), сцена (пусто), длина, loop/oneshot, запасной ванильный звук, статус, риск, имя файла.
Ориентиры сцен из поиска (серия 52 старого аниме для банкая Бьякуи, TYBW для банкая Рукии) в конце листа, помечены непроверенными. Описания «что слышно» написаны по общим знаниям, не сверены с эпизодами.
Настоящих loop-звуков нет: «loop» значит, что код повторяет событие через интервал; клип должен быть бесшовным или затухать.
