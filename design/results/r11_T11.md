# R11 T11: меч не ломает траву (сделано в коде, тесты зелёные, в игре не проверено)

Логика Better Combat 2.4.0 (javap `MinecraftClientInject`): клик по блоку копает блок вместо взмаха, если `isTargetingMineableBlock()`. Для травы это значит: взмах только если включён `isSwingThruGrassEnabled`, блок без коллизии и твёрдость 0, и (в «умном» режиме `isSwingThruGrassSmart`) в зоне досягаемости уже есть цель. Без цели умный режим даёт копать траву, взмах не начинается. Это и есть жалоба.
Решение: пока в основной руке зарядный меч и нет открытого экрана, `client/BcGrassSwing` выключает Smart (и включает swing-thru) в живом конфиге BC (публичные поля), при смене предмета/экране/выходе возвращает значения игрока. Если поля BC недоступны, лог `[grass]` один раз.
Сервер: `server/GrassGuard` (Fabric `PlayerBlockBreakEvents.BEFORE`) не даёт сломать мечом блок без коллизии с твёрдостью 0 (трава, цветы, папоротник), кроме креатива. Чистое правило `core/combat/SwingThruRules` + тест.
Камень, земля и всё твёрже копаются как раньше. Вариант «меч не копает вообще» предложить пользователю.
Руками (по желанию): в `mod/run*/config/bettercombat/client.json5` поставить `isSwingThruGrassSmart: false`. Файлы не менял.
UNVERIFIED: что взмах начинается на траве; что BC не пересохраняет временные значения (конфиг пишется только при сохранении из меню настроек, а при открытом экране значения возвращаются).
