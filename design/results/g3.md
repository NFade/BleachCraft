# G3: voice matching of live Russian and English speech (2026-10-11)

Task: the fixtures passed 202/202 but the live microphone did not fit the spoken names to the spells. Only code and tests
were changed; no game, no microphone. Everything below that depends on what a real recogniser says is UNVERIFIED.

## What was measured (offline, no audio)

A scratch harness (outside the repo) ran 287 "dirty" renderings of the 14 commands through the matcher: split and glued
words, vowel and voicing slips (`hack you wren`, `send bonds a cura`, `kaga yoshi`), hesitations and polite words around
the command (`uh seal`, `okay bankai please`), Cyrillic spellings. Baseline before the change: 248/287. After: 270/287
(the 17 left are listed below on purpose). The 202/153 fixture stays 202/202 and 0 false positives.

False positives were compared against the old code on 84 000 random sentences (vocabulary of command-like words and
mutations of every variant, 3 seeds): the only new hits are the new aliases themselves and mutations of them.

## Causes found

1. Hesitations (`uh seal`) blocked the weak variants (`seal`, lone `chire`): the whole-utterance rule only knew 9 filler
   words.
2. Keys that the letter folds shorten to 6 letters become exact-only: `kageyoshi` -> `kagesi`, `bankai`, `senkei`. Any
   vowel slip (`kagayoshi`, `bankay`, `senkay`) missed.
3. A name split into three or more small words (`send bonds a cura`, `she ra yuki`) was out of reach: fuzzy windows allow
   one extra word only.
4. Voiced/unvoiced swaps (g/k, d/t, b/p) and the stop that recognisers insert after n (`send` for `sen`) cost 2-3 edits
   on long names and the per-token rule then rejects them.
5. Web Speech was asked for one hypothesis (`maxAlternatives = 1`), so a correct second guess was thrown away.

## Changes

- `core/voice/LooseKey.java` (new): second key that folds only consonants (g/k, d/t, b/p, v/p, c/k, w/u, `nt` before a
  consonant, runs); vowels stay so the key keeps its information. A first version that also collapsed vowels was dropped:
  it produced dozens of new false positives (`queen семена золото` firing Shirayuki).
- `core/voice/PhraseMatcher.java`: after the strict pass finds nothing for a non-weak variant, a loose pass runs, only
  for variants with a loose key of 11+ letters. Guards: up to n+3 tokens, at most one interior single-letter fragment,
  aligned words must be close both loose and strict (a shared prefix `senbonzakura` cannot carry a different last word),
  Jaro-Winkler at least `minSimilarity + 0.02`, confidence capped at 0.97 (exact loose compact: 0.95), so a strict hit
  always outranks it. Strict code paths are untouched.
- `tools/gen_voice_phrases.py` -> `phrases.json` (regenerated, 210 -> 265 variants, 9 -> 24 fillers): more fillers (`uh um er ah oh
  hmm so yeah then эм ага так вот ладно тогда`); aliases for the exact-only and over-split names (list in the script, with
  the reason); `seal your sword / my sword / the blade`, `запечатай катану`. Rule written into the script: never add a
  spelling whose key equals the gated `bank eye` family (`bankei`), nor `sankei` (key equals `sankey`).
- Alternatives: `VoiceMessage.alternatives` (compat constructor kept), `VoiceHttp.parse` reads optional `"alts"` (max 4),
  `VoiceProcessor` tries up to 3 alternatives of a FINAL result that matched nothing (NO_MATCH, WEAK_NOT_WHOLE, AMBIGUOUS,
  GATED_OUT), only with confidence >= 0.93 (`ALT_MIN_CONFIDENCE`); a debounced or interim main result is never rescued.
  `voice-bridge/index.html`: `maxAlternatives = 3`, sends `alts` with the final. The node session tests still pass (26).
- `server/VoiceControl.java`: every unmatched FINAL is now logged at INFO as `heard "<raw>" (lang) key='<normalised>'
  alts=<n> -> <outcome>`, and the FIRED line carries the key and the matched variant. This is the tuning data for the
  first live session (read `latest.log`, no audio involved).

## Tests

New: `DirtyPhraseFixtureTest` (7 tests: 270 dirty positives all fire, 81 dirty neutrals never fire in 25 contexts, loose
confidence below strict, `bank eye` family still gated, fillers vs the whole-utterance rule, 3000 random everyday
sentences x 25 contexts never fire), `LooseKeyTest` (5), `VoiceAlternativesTest` (10), `VoiceHttpAltsTest` (4) = 26 tests,
and `tests/voice/dirty_fixture.json` (270 + 81 phrases). Full `gradlew test`: 360 tests, 0 failures (the 17 left outside the fixture: see below). The old `phrases_fixture.json`, `MatcherFixtureTest` and the
other voice tests are unchanged.
