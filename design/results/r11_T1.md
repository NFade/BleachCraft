## 1. Какая сторона клинка это кромка (проверка по сетке)

Метод: `drawn.obj` обоих мечей (`models/obj/byakuya_sealed/byakuya_sealed_drawn.obj`, `models/obj/rukia_sealed/rukia_sealed_drawn.obj`), сечения плоскостями, перпендикулярными оси клинка (OBJ +Y, `blade_axis.direction` меты `[0,0,1]` в Blender Z-up переводится `AxisMapper.blenderToObj`: `(x, y, z) -> (x, z, -y)`, то есть OBJ +Z = Blender -Y). В предметной модели `p_mc = p_obj - grip + (0.5, 0.5, 0.5)` без смены осей, значит модельная ось +Z = OBJ +Z. В каждом сечении взяты вершины в пределах 20 процентов толщины у каждого края по Z и измерена ширина по X (у кромки сечение сходится в линию, у спинки толстое):

| Сечение по оси клинка (OBJ y) | ширина по X у z_min (спинка) | ширина по X у z_max (кромка) |
|---|---|---|
| 0.40 | 0.0090 | 0.0010 |
| 0.55 | 0.0080 | 0.0010 |
| 0.85 | 0.0055 | 0.0010 |
| 0.95 | 0.0040 | 0.0010 |

Числа одинаковы для Бьякуи и Рукии (клинки общие по сетке). Вывод: у ОБОИХ мечей кромка это +Z модели (в Blender это -Y), спинка -Z. Совпадает и с сори: центр дуги в меле на Blender +Y (`sori_arc.center`), острие уходит к спинке, то есть к -Z модели. Допущение `TpPose` (`orient`: модельная +Z = кромка) подтверждено, поворот на 180 градусов не нужен.

### Известный компромисс (одноручный запасной блок)

Одноручный блок используется только когда выключено двуручное держание (`fp_two.enabled = 0`). С кромкой вперёд ванильная рука (правая) при повороте на 90 градусов вокруг клинка оказывается ближе к камере, и все прежние правила сразу выполнить не удаётся: статические (в покое блока) выполнены, а при ВХОДЕ в блок свободная левая рука на 0.03 с заходит на 0.07 ndc в центральный прямоугольник (поле -0.067, раньше 0.137; `FpCentre` в блендинге тестом для одноручного не проверяется, в покое блока поле 0.14 и выше). Пользователю это можно не править, пока двуручное держание включено. Если нужно, можно заменить запасной блок на ту же позу, что у двуручного.

## 4. Тесты (пины, что изменено и почему)

Все изменения только там, где пин определял прежнее положение кромки или прежний путь блендинга; ни один порог безопасности (`FpCentre`, `FpClamp`, `CorePurityTest`, near-plane 0.15, поле рук 0.2/0.1, 8 градусов к прицелу, поле клинка 0) не ослаблен.

- `BlockPoseFpTest.theBladeAndTheEdgeHaveTheDirectionsOfTheUsersPose`: `TARGET_EDGE` `(0.861, 0.509, 0)` -> проекция `(0,0,-1)` (допуск 1 градус), `edge.z < -0.998`, поворот на 90 градусов против R10 (допуск 3), плоскости клинка во фронтальной плоскости (`|z| < 0.05`, раньше `> 0.99`: плоскости теперь не смотрят вперёд). Направление клинка по-прежнему в пределах 1 градуса.
- `BlockPoseFpTest.theBlendFromTheStanceIsSmoothAndSafe`: суммарный поворот `< 140` заменён на `< 70` (стало строже: 52 градуса); остальное без изменений, подхождение при блендинге 0.14 против 0.107 у r8 (проверка `fresh >= old`).
