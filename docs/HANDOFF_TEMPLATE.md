# Шаблон handoff для нового чата (до 1.5k токенов)

Положи заполненный файл в `NEW_CHAT_PROMPT_<имя>.md` (не коммитить) и начни новый чат фразой «прочитай и начни».
Не пиши то, что есть в коде, в `STATUS.md` или в `git log`. Только то, чего там нет.

```
Ветка и worktree: <имя ветки>, путь <...>. База: <ветка>.
Задача (1-3 строки): <что делаем и что считается готовым>.
Сделано (факты, не пересказ): <5-8 пунктов с путями файлов>.
Проверено: <сборка/тесты: число>. НЕ проверено в игре: <список>.
Открытые решения пользователя: <вопросы, которые ждут ответа>.
Подводные камни этого этапа: <2-4 пункта, например знак поворота, кэш ключей>.
Следующий шаг: <1 конкретное действие>.
Не трогать: <файлы/ветки>.
```
